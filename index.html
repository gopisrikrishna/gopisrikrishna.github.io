Public repository · MCP server

solarnetwork-mcp

An MCP server that lets AI agents read solar telemetry, find dated equipment faults, estimate lost energy and write a technician work order. Its rule: it says “not assessed” when the data can’t support an answer, instead of guessing “healthy”.

  • 10 tools from fleet discovery to PDF service reports
  • Peer-relative fault detection across a fleet of public SolarNetwork nodes
  • Honest by design: handles gaps, rate limits and missing data explicitly
